OFF/AXIS — offaxis-creative.com
================================

Uploading to GitHub Pages
1. In your existing repo, delete the old site files, but KEEP the CNAME file
   (it holds your domain; without it the custom domain stops working).
2. Upload everything in this folder to the root of the repo
   (index.html must sit at the top level, next to CNAME).
3. Commit to the branch GitHub Pages publishes from (usually main).
4. Wait a minute or two for Pages to rebuild, then open the site.
5. In Cloudflare: Caching > Configuration > Purge Everything,
   so visitors get the new files instead of the old cached ones.

Before you go live
- Open the contact form and send yourself a test message (Formspree).
- Check the site on your phone and on a desktop browser.
- Delete this README from the repo if you don't want it public (optional).

Parked material (not part of the live site)
The car work, photo series and surveys page are in the separate
"offaxis-parked" zip, ready to bring back later.
